# 房屋 3D

直接用浏览器打开 `index.html`。目录内已包含 Three.js 和户型图，可离线使用，不需要安装依赖。

沿用原页面的三维剖面与暖灰信息面板风格，根据 `户型图.png` 新建两室一厅模型，并参考实拍照片还原墙地面、门窗、柜体、家具、家电和卫浴设备。右侧 2.03 m² 空间是厨房所属的小阳台，从厨房门洞进入。

墙地面材质参考：

- 客餐厅、主次卧、阳台墙面：暖白乳胶漆，细微哑光肌理。
- 主次卧地面：浅橡木色，顺直细木纹、错缝铺设。
- 客餐厅、厨房、厨房小阳台地面：浅米灰石纹砖；客厅阳台使用同色系砖面。
- 厨房、卫生间、厨房小阳台内侧墙面：浅灰石纹墙砖；共用墙的客厅侧保持暖白。
- 卫生间地面：浅灰防滑石纹砖。

纹理由 Canvas 程序生成，颜色为照片光照下的近似还原，拼缝尺寸按常见砖板规格估算。纹理按米映射，切换墙高时仍保持相同的砖缝比例，并避开门窗洞口。

门窗参考实拍照片，安装在已有洞口中：

- 入户门：深棕色门板、门框、锁具与猫眼。
- 主次卧：浅木色平开门、门套、细分缝、黑色把手与合页。
- 厨房：深灰铝框双扇玻璃推拉门，带上下轨道和拉手；厨房右侧为实体墙，无窗。
- 卫生间：门和邻厨房小阳台的窗均使用偏黑灰色毛玻璃，带细微磨砂颗粒，降低透视感。
- 各房间及阳台：深灰铝合金窗框、分扇玻璃、执手与浅色石材窗台；6 组对外窗另有纱窗框、细密纱网及独立安装层。
- 阳台三面采用落地窗，洞口下沿距阳台完成地面 10 cm，玻璃和纱窗随洞口延伸。阳台地面标高为 -0.018 m，对应窗下沿模型标高 0.082 m。
- 次卧保留下方窗户，左侧灰色墙段补回实体墙。户型图中的实心灰色表示非承重墙，不作为窗洞。
- 厨房至小阳台、客厅至阳台均保留开放通道；客厅阳台入口没有门扇、门框或轨道。

共 5 组门、7 组窗，其中 6 组对外窗带纱窗，另 1 组为卫生间与厨房小阳台之间的毛玻璃窗。点击「关闭房门 / 打开房门」统一控制平开门及推拉门，默认开启。门窗保留完整高度，不跟随墙体剖切；切换完整墙高不会重置开合状态。开向参照户型图，门窗样式与未标注构造尺寸按照片近似还原。

共 8 组柜体。保留房门开启与窗户位置，厨房柜体从入口后退约 0.72 m 留出转身空间。柜体尺寸并非现场测量值；洗手区按户型余量缩放。厨房高台面及下方柜体顶板为水槽留出开孔。可通过「隐藏柜体 / 显示柜体」对照户型，柜体不随墙高切换而截断。

洗漱台参照「客厅-站在入户门看客厅」照片：凹位朝北向餐厅开口，西侧补隔墙，内侧墙面和地面贴灰砖。洗漱台独立于卫生间门，台盆为凹陷盆体，镜子使用房间环境反射近似显示，并随门扇和墙高变化更新。隔墙归属墙体，隐藏柜体时保留。

厨房实拍可见东北内角的贴砖凸墙，以及灶台低、水槽高的台面高差。凸墙归属墙体，隐藏柜体后仍保留；地柜和吊柜分段避让，低台面绕墙收口，与高台面交接处加不锈钢立边。凸墙占地暂估 0.42 × 0.36 m，高差暂估 0.08 m，均待实测确认。

- 拖拽旋转，滚轮或双指缩放，Shift / 鼠标右键拖拽平移。
- 默认显示完整墙高，可切换为剖面墙高；支持全屋、俯视及各房间视角。
- 支持隐藏标注、查看原图和导出当前视角 PNG。
- `index.html#top` 可直接打开俯视图。

原图最大宽度 9.44 m，进深 9.03 m。优先使用图中标注尺寸搭建；层高暂设 2.70 m，未标注的墙厚和洞口尺寸按图估算。图中的局部尺寸与面积不完全一致，页面面积保留原图标注（合计 54.98 m²，含两个阳台），不是模型实测面积。俯视与剖面均用于空间理解，不作为施工图。
